How to install

  1. Tap the download button of the game you want. The file starts downloading right away. You can install both games on the same phone.

  2. If your browser warns that the file type is unusual, tap Download anyway. This is expected for apps installed outside the Play Store.

  3. Open the downloaded file. If asked to allow installs from this browser, tap Allow — you'll only need to do this once.

  4. Tap Install, then Open to start playing.
